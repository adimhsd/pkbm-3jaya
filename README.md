# PKBM TRI JAYA 🎓

Website resmi Pusat Kegiatan Belajar Masyarakat (PKBM) Tri Jaya Kabupaten Kuningan.

## 📖 Tentang PKBM Tri Jaya

PKBM Tri Jaya adalah lembaga pendidikan nonformal yang menyediakan program pendidikan kesetaraan:
- **Paket A** - Setara Sekolah Dasar (SD)
- **Paket B** - Setara Sekolah Menengah Pertama (SMP)
- **Paket C** - Setara Sekolah Menengah Atas (SMA)

Semua program diakui dan disetarakan oleh pemerintah. Kami berkomitmen memberikan akses pendidikan berkualitas bagi masyarakat yang ingin melanjutkan atau mengejar kesetaraan pendidikan formal.

## 🚀 Cara Menggunakan Project

### Prasyarat
- Text editor (VS Code, Sublime Text, dll)
- Git untuk version control
- Firebase CLI (untuk deployment)
- Web browser modern

### Setup Lokal

1. **Clone repository**
   ```bash
   git clone https://github.com/adimhsd/pkbm-3jaya.git
   cd pkbm-3jaya
   ```

2. **Buka di browser**
   - Langsung buka file `public/index.html` di browser, atau
   - Gunakan live server extension di VS Code

3. **Modifikasi konten**
   - Edit file HTML di folder `public/`
   - Edit style di `public/style.css`
   - Edit script di `public/main.js`

### Deploy ke Firebase Hosting

1. **Install Firebase CLI**
   ```bash
   npm install -g firebase-tools
   ```

2. **Login ke Firebase**
   ```bash
   firebase login
   ```

3. **Deploy**
   ```bash
   firebase deploy
   ```

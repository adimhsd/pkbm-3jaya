# 🎓 PKBM TRI JAYA - Website Profil Resmi

Website profil lembaga pendidikan non-formal **PKBM TRI JAYA** yang responsif, modern, dan ringan. Dibangun dengan prinsip *Mobile-First* untuk memudahkan masyarakat mengakses informasi pendidikan kesetaraan.

## 🚀 Demo & URL
- **URL Live:** [https://pkbm-3jaya.web.app](https://pkbm-3jaya.web.app)
- **Hosting:** Firebase Hosting
- **Deployment:** Otomatis via GitHub Actions (CI/CD)

## ✨ Fitur Utama
- **Landing Page Informatif:** Etalase keunggulan lembaga.
- **Katalog Program:** Informasi detail Paket A, B, dan C serta vokasi.
- **Pendaftaran Online:** Integrasi formulir menggunakan Google Form (Embedded).
- **SEO Lokal:** Optimasi kata kunci wilayah untuk pencarian Google.
- **Responsif:** Tampilan optimal di smartphone, tablet, maupun desktop.
- **Fast Loading:** Menggunakan Tailwind CSS untuk performa maksimal.

## 🛠️ Teknologi yang Digunakan
- **HTML5 & CSS3** (Custom Styling)
- **Tailwind CSS** (Utility-first CSS Framework)
- **Vanilla JavaScript** (Interaksi Menu & UI)
- **Firebase Hosting** (Infrastruktur Web)
- **GitHub Actions** (Automated Deployment)
